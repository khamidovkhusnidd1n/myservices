# KHAMIDOV DIGITAL STUDIO

**DIGITAL SUPREMACY ENGINEERED.**

This is the source code for the elite digital agency portfolio of [Khamidov Studio](https://t.me/khusniddinkhamidov). 
Built with a Brutalist aesthetic, raw performance, and zero compromises. We don't use templates. We write code.

## Tech Arsenal
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Brutalist theme, raw CSS animations)
- **i18n:** `next-intl` (English, Russian, Uzbek)
- **Deployment:** Vercel / Netlify ready

## Local Development

If you have what it takes to run this locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and prepare to be intimidated.

## Architecture & Principles
- **No Drag and Drop:** Raw code. High performance.
- **Strict Typing:** TypeScript enforced across all modules.
- **Internationalization:** Deeply integrated localization for global domination.
